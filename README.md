<h1 data-importer="text" align="center">Attendance Management System</h1>

###

<h2 data-importer="text" align="left">About the project</h2>

###

<h5 data-importer="text" align="left">The Attendance Management System is a simple Python program that helps users manage student attendance. It allows users to add students, mark them as present or absent, record their arrival time, and view their attendance records.</h5>

###

<h2 data-importer="text" align="left">Features</h2>

###

<h5 data-importer="text" align="left">Add Student – Adds a student to the attendance list.<br><br>Mark Attendance – Marks a student as present or absent.<br><br>Enter Time of Arrival – Records whether a student is late or on time.<br><br>View Attendance – Displays all students and their attendance records.<br><br>Input Validation – Checks for empty names, duplicate students, invalid menu choices, and incorrect time formats.</h5>

###

<h2 data-importer="text" align="left">Limitations</h2>

###

<h5 data-importer="text" align="left">No Permanent Storage – Student records are stored in a dictionary and are lost when the program closes.<br><br>Manual Data Entry – Users must manually enter student names and attendance information.<br><br>Fixed Late Schedule – The program considers students arriving after 7:00 AM late.<br><br>Basic Time Validation – The program checks the time format but does not fully validate whether the entered hour and minute are valid.<br><br>No Editing or Deleting Students – There are no options to remove a student or edit their name.<br><br>No Attendance Reports – The program cannot generate daily, weekly, or monthly attendance summaries.<br><br>Text-Based Interface – The program runs in a terminal and does not have a graphical user interface.<br><br>Case-Sensitive Names – Student names must be entered with the same capitalization used when they were added.</h5>
